# Solum Soft - Web Landing Page

Este repositorio contiene el código fuente de la página de aterrizaje (landing page) de **Solum Soft**, una factoría de desarrollo ágil especializada en diseñar soluciones de software a medida para PyMEs. Nuestro objetivo es reemplazar el caos operativo con aplicaciones web robustas y escalables.

## 🚀 Pilares Principales

- **Simplicidad Extrema (UX Premium)**: Interfaces minimalistas de grado industrial, diseñadas para ser intuitivas y eliminar la fricción.
- **Agilidad sin Fricciones**: Desarrollo de soluciones a medida en plazos promedios de 15 a 21 días.
- **Cercanía y Empatía Real**: Modelado de los flujos de trabajo reales de la PyME, adaptándonos al negocio en lugar de obligarlos a usar procesos enlatados.
- **Acompañamiento Continuo**: Soporte técnico directo y cercano para asegurar el crecimiento del negocio.

## 🛠 Tech Stack

- **Frontend**: React.js + Vite.
- **Estilos**: Tailwind CSS.
- **Animaciones**: GSAP + Lenis (para smooth scrolling).
- **Íconos**: Tabler Icons / Lucide React.
- **Base de Datos / Backend**: Preparado para integrarse con Supabase (PostgreSQL).

## 💻 Comenzando

Para correr el proyecto en modo desarrollo, asegúrate de tener Node.js instalado y sigue estos pasos:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar el servidor de desarrollo
npm run dev

# 3. Compilar para producción (cuando esté listo para deploy)
npm run build
```

## 📂 Estructura del Proyecto

- `/src/assets`: Imágenes, logos y recursos estáticos.
- `/src/components`: Componentes UI y secciones principales de la web (Hero, Quadrants, SuccessCase, etc.).
- `/src/App.tsx`: Ensamblado principal de la landing page.
- `/index.html`: Archivo de entrada HTML, optimizado con meta etiquetas para SEO.

## 📈 SEO y Optimización
La web incluye optimizaciones SEO (Meta Description, Keywords) y compatibilidad con Open Graph (Facebook/LinkedIn) y Twitter Cards, para asegurar una previsualización adecuada al compartir los enlaces.
